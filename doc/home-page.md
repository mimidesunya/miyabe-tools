# トップページ（自治体マップ）

トップページは、上から「検索の箱」「自分のまちから探す」「各地のお知らせ」「地図で見る」の順に並びます。
画面全体の決まり（言葉・色・共通のヘッダー）は [site-design.md](site-design.md)、各地のお知らせは [news.md](news.md)。
この文書は、地図と自治体の一覧の描き方を扱います。実行状態管理の正本は
[status-architecture.md](status-architecture.md) を、自治体単位の共通設計は
[multi-municipality.md](multi-municipality.md) を参照してください。

## 描画方式

- トップページ本体は `/api/home.php` を `fetch` して、自治体対応状況の地図を描画します
- 地図と自治体一覧は自治体文書（会議録・例規集）だけを表示します。選挙ポスター掲示場は `/boards/` の独立ページで扱い、自治体一覧に「掲」や掲示場の状態を表示しません
- Leaflet と国土地理院タイルを使い、市区町村マーカーで対応状況を確認できます（都道府県集約の円マーカーは分かりにくいため廃止）
- ポップアップは `autoPan` を無効にします。moveend 再構築時の再表示と連鎖して、選択中の自治体へ地図が勝手に流れるため
- 市区町村マーカーの代表点は `F:\home\person-geo\geo\yahoomap-2019\cities.txt` から生成した `app/assets/js/municipality-coordinates.js` を使います
- トップ最上部に検索の箱を置きます（資料の種類のタブ（会議録・例規集・事務事業評価）・言葉の欄・その資料の短い説明・例の言葉・「検索のコツ」）。例の言葉は資料の種類ごとに、その資料で実際に当たる言葉にします。自治体名は本文中の語として検索されるだけで絞り込みではないので、「検索のコツ」で、絞り込みは結果の画面でできると書きます。送信先は `/search/` で、結果表示と細かい絞り込み（都道府県・自治体・期間・並び順）は `/search/` の仕事です。トップ側に結果一覧やファセットを持ち込まないこと
- 検索の箱の下に、いま検索できる自治体の数を 1 行で出します（`[data-home-coverage-line]`、`home.js` の `renderCoverageLine`）。段階ごとの内訳は `/status/` の仕事です
- 「自分のまちから探す」は、地図と同じ `/api/home.php` のデータから名前で候補を出します（`home.js` の `bindTownPicker`）。選ぶと、その自治体の会議録・例規集・事務事業評価への入口が出ます
- 全国を出すときの地図の範囲は、北海道から九州に合わせます。点の全部（沖縄・小笠原まで）に合わせると本州が小さくなるためです
- 時刻表示は `Asia/Tokyo` に揃えます

## 描画の軽量化ルール

自治体数が多い（1,500件超）ため、次の方針でクライアント描画を軽く保ちます。

- ズームアウト時は canvas の circleMarker、ズーム 7 以上は DOM ピンの 2 モード
- マーカー・ツールチップ・ポップアップは選択中の文書機能だけを表示します。他方の文書機能の対応状況は詳細パネルと一覧で確認します
- `assets/` の JS/CSS は `site_asset_url()` が `filemtime` を `?v=` として付けて配信します。nginx 側の長期 immutable キャッシュはこの版付き URL が前提なので、版なし URL に戻さないこと（ローカルの `app/` とコンテナの `/var/www/html` の両レイアウトを解決します）
- DOM ピンは地図の表示範囲（＋余白 3 割）に入る自治体分だけ生成し、移動・ズームのたびに組み直します
- ツールチップとポップアップは全マーカー分を事前生成せず、hover / クリック時に初めて生成します
- 自治体の選択切り替えでは地図と一覧を再構築せず、対象マーカーと一覧行のスタイルだけ更新します
- 60 秒ごとの自動更新は API 応答が前回と同一なら再描画をスキップし、再描画する場合も視点（中心・ズーム）を保ちます。視点の自動フィットは初回描画と絞り込み変更時だけです

## API とデータ

- `/api/home.php` は自治体文書だけのトップページ用カタログです。選挙ポスター掲示場の機能・状態・集計は返しません
- 会議録・例規集がどちらも非表示の自治体は返しません
- 実行状態の正本は PostgreSQL の管理テーブルです
- `/api/home.php` は PostgreSQL の自治体カードを読み、会議録・例規集の live 状態を重ねて返します
- 自治体カタログや公開件数の重い再計算結果は派生ビューとして PostgreSQL に保存します
- `data/background_tasks/*.json` はスクレイパが PostgreSQL と同時に書く控えで、表示の正本ではありません（[status-architecture.md](status-architecture.md)）

## 表示ルール

- 実行中タスクの時刻は `開始`、待機中タスクの時刻は `完了` として表示します
- 会議録・例規集の公開検索への反映は、通常はスクレイプ完了自治体だけを OpenSearch alias 上で差し替えます
- 全量再構築が必要なときは versioned index を作って alias を切り替える方式です
