# 自治体一覧

`/municipalities/` は、会議録・例規集・事務事業評価を**自治体自身がどこで
公開しているか**を並べる画面です。リンク先はこちらの検索ではなく、
自治体のサイトそのものです。

トップページの地図が「こちらで何を持っているか」を見せるのに対し、
この画面は「原典がどこにあるか」を見せます。こちらの収録を疑ったときに、
読者が 1 手で原典へ行けるようにしておくためのものです。

## 並べ方

- 地方（8 区分）→ 都道府県 → 自治体コード順
- 地方の区分は `municipality_region_for_prefecture()`（`lib/municipalities.php`）。
  都道府県コードの並びをそのまま使います。中部を北陸・甲信越・東海へ割る
  流儀もありますが、分けていません
- 表の列は コード / 自治体 / 会議録 / 例規集 / 事務事業評価

## 表示ルール

- リンクの文字はホスト名だけにします。URL 全体は `title` に入れます。
  1,794 行あるので、1 行を短く保たないと読めません
- URL が無い欄は理由を短く出します。`未特定` / `公開なし` / `映像のみ` /
  `要ログイン`。**「未特定」は公開していないという意味ではありません。**
  この調査手順で確定できなかった、という意味です
- 事務事業評価の `要確認` は、評価の入口は見つかったが中身の確認が
  済んでいないものです（登録簿の `crawl_status=review_required`）
- 外部リンクには `rel="noopener nofollow"` を付けます。原典への案内であって、
  こちらが評価しているわけではありません

## データ

`data/municipalities/` の 3 つの登録簿と自治体マスタだけを読みます。
検索インデックスにも PostgreSQL にも触れないので、収集が止まっていても
この画面は出ます。

- `assembly_minutes_system_urls.tsv`
- `reiki_system_urls.tsv`
- `hyoka_system_urls.tsv`
- `municipality_master.tsv`

## 注意

PHP は「13101」のような数字だけの配列キーを int にします。JIS コードを
キーに回すときは 5 桁、都道府県コードは 2 桁へ戻してから使ってください。
戻し忘れると、途中で型エラーになって**ページが途中で切れます**（実際に
関東までしか出ない状態を作りました）。
