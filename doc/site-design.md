# 画面の作りと言葉（2026-11-14 に作り直し）

公開の画面（トップ・検索・詳細・自治体一覧・AIで調べる・収集状況・規約など）に共通の決まりです。
画面を足す・直すときは、ここに合わせてください。トップの地図の描き方は [home-page.md](home-page.md)。

## だれのために作るか

政治に関心はあるが、情報技術には詳しくない人です。スマホで来る人も多い。

- 文字は大きめ（本文 16px、行間 1.75）。押す所は指で押せる大きさ（高さ 44px 以上）。
- 言葉はふだんの言い方を先に出し、役所の呼び名を添える。
  - 会議録 → **議会の発言**（会議録）
  - 例規集 → **条例・規則**（例規集）
  - 事務事業評価 → **事業の評価**（事務事業評価）
  - 原典・原サイト → **自治体のサイト**、ヒット → **見つかりました**、ソート → **並べ方**
- 取得の仕組みの名前（`site-gikai-pdf` など）、応答の ms、MCP のような内部の言葉は、画面の本筋には出さない。
- 飾りの見出し・スローガン・番号だけの飾り（01 / 02）は置かない。見出しは、そこで何ができるかを言い切る。

## どのページでも同じ枠

`lib/site_assets.php` の `site_render_header($current)` と `site_render_footer()` を使います。
スタイルは `site_render_stylesheet()`（`app/assets/css/site.css`）を、ページ専用の CSS より前に読みます。

行き先は 5 つで、言葉と順番はどのページでも同じです（`site_nav_items()`）。

| 鍵 | 言葉 | 先 |
|---|---|---|
| `home` | ホーム | `/` |
| `search` | 検索 | `/search/`（詳細・例規の本文もここ） |
| `municipalities` | 自治体一覧 | `/municipalities/` |
| `ai` | AIで調べる | `/api-guide/` |
| `status` | 収集状況 | `/status/` |

- スマホ（幅 860px 未満）は、画面の下に固定のタブ。`body` の下に、その高さぶんの余白が入っています。
  下に貼り付ける部品を足すときは、`--tab-bar` の分だけ上げてください（例: 例規の頁送り）。
- PC はヘッダーの右に並びます。
- 規約・プライバシー・お問い合わせは、フッターから行きます。

## 色

色は **3 種類の資料の見分け**に使います。飾りには使いません。

| 資料 | 色 | 変数 |
|---|---|---|
| 会議録 | 藍 `#1c4f9c` | `--minutes`・`--minutes-deep`・`--minutes-tint` |
| 例規集 | 緑 `#1a6e45` | `--reiki`・… |
| 事務事業評価 | 柿 `#a34d0c` | `--hyoka`・… |

- 要素に `data-doc="minutes|reiki|hyoka"` を付けると、その中の `--doc`・`--doc-deep`・`--doc-tint` が入れ替わります。
  検索の画面は `body` に付け、資料を切り替えると画面全体の色が変わります。
- 同じ色を、検索の箱のタブ・結果の札（`.doc-badge`）・地図の点で使います。
  地図の点の色は JS に直に書いてあるので、変えるときは `app/assets/js/home.js` の `featureMeta` と
  `app/search/assets/js/search.js` の `HIT_MAP_COLORS` も合わせます。
- 押せるもの・いまいる場所は藍（`--accent`）。検索で当たった言葉は蛍光ペンの黄色（`mark`）。
- 状態は 4 色: できている（`--ok`）・待ち（`--wait`）・だめ（`--bad`）・対象外（`--off`）。

## 文字

`--font`: BIZ UDPゴシック → ヒラギノ角ゴ → Noto Sans JP → 游ゴシック。Web フォントは読み込みません
（日本語のフォントは重く、外部への通信も増える）。長い本文（会議録の全文）は `--font-read`（明朝）。

## 検索の箱

トップと検索の画面で同じ形です（`site.css` の `.search-box`・`.doc-tabs`・`.doc-tab`・`.search-row`）。
書類の見出しタブのように 3 種類の資料を切り替え、選んだタブと箱の枠がその資料の色になります。

- トップは `radio`（JS が無くても `doc_type` を付けて `/search/` に送れる）。説明と例は `:has()` で切り替えます。
- 検索の画面は `button`（`data-doc-type`）。`search.js` が `body` の `data-doc` を書き換えます。

## 検索の画面

- 上から「検索の箱」「結果」。**スマホでは絞り込みを畳んでおき**、結果が最初の画面に入るようにします。
  絞り込みは「絞り込み」ボタンで開き、いくつ効いているかをボタンに出します。PC は左に並びます。
- 絞り込みの欄は `<form id="search-form">` の外にあり、`form="search-form"` でつないでいます。
- 見つかった自治体の地図は、スマホでは最初は畳みます。
- 結果の 1 件は「資料の札・自治体・日付 → 題名（詳細へ）→ 抜粋 → 全文を読む／自治体のサイトで見る」。
  詳細は同じタブで開き、詳細の「検索の結果に戻る」で同じ結果（頁・絞り込み・地図の位置）に戻ります。

## トップ

上から「検索の箱」「自分のまちから探す」「各地のお知らせ」「地図で見る」「ほかの調べ方」。

- 「自分のまちから探す」は、名前を入れると地図と同じデータから候補を出し、その自治体の
  会議録・例規集・事務事業評価への入口を出します。集めていない資料は、押せない形でそう書きます。
  事務事業評価のある自治体は、ページに埋めた一覧（`#home-hyoka-slugs`）で見分けます。

## 手元で画面を確かめる

データは本番の公開 API から借り、画面は手元のファイルで出します（本番に書き込むことはありません）。

```bash
php -S 127.0.0.1:18091 -t app dev/preview/router.php
php -S 127.0.0.1:18092 dev/preview/opensearch_stub.php   # 詳細の画面を見るときだけ
```

- `/api/` への GET を `https://tools.miya.be` へ取りに行き、10 分だけ手元に控えます。
- 詳細の画面は PHP が OpenSearch を直に読むので、2 つ目の入口が `/api/document` から 1 件を作って返します。
- スマホの幅（375px）と PC の幅の両方で見てください。
